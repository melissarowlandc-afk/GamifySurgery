# Gift Shop proof

[Open the comparison](http://127.0.0.1:4191/tools/room-design/level-5/gift-shop/proof/index.html): static room-first concept beside the playable Canvas, stacking at narrow widths. Twelve door toggles, three backing controls, five fixed-look upgrade buttons, four standing shopper controls, routes, anchors and measured floor bases.

The renderer, native engine and validation pattern mirror the Executive Office toolchain. `geometry.mjs` is shared between native and browser proof only. Nine transparent concept-derived sprites form eleven floor records; one necessary joined checkout/main display and all four standing spots retain their geometry for every door. Optional visible stock supplies optional browse contacts. Characters avoid its footprints and bases, plus other shown shoppers.

Current evidence: `evidence/v3/`; historical evidence: `evidence/v1/`, `evidence/v2/` and the preserved complete v2 snapshot. Native PASS is separate from browser QA/owner approval. Manager browser validation also checks concept delivery, desktop comparison placement, actual controls, 320px overflow, source hashes and page errors.
