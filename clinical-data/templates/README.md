# Clinical authoring templates

Use [the question authoring standard](../../docs/clinical/question-authoring-standard.md)
for question design, evidence/review requirements, three/four credible options,
owner difficulty targets and advisory lint. The JSON template remains the
normalized authoring schema; question-review notes must not be inserted as
unknown fields. See the [field guide](../../docs/clinical-workbench/PILOT_FIELD_GUIDE.md)
for record sequencing and the current boundary before runtime question authoring.
