# Clinic environment atlas v1

`clinic-environment-atlas-v1.png` is original AI-generated project artwork for
Stitchin' Time. It was created from the project's approved `Photos for Codex`
references as art-direction input only; it is not a copied third-party asset or
a flattened clinic screenshot.

The live renderer uses measured, named source rectangles from this one atlas for
independent grass, sidewalk, floor, and architectural layers. Domain room
geometry, doors, pathing, interaction targets, and build-mode placement remain
separate from the artwork. The source SHA-256 is
`FE663ED5A35AFCE37DA50CA69E7B51E1F19B4479006F7C751B1CCBF4C3309E7D`.

## Landscaping atlas v1

`clinic-landscaping-atlas-v1.png` is a separate original transparent PNG layer
for trees, shrubs, flower beds, an exterior bench, and entrance planters. The
connected-edge background removal pass preserves enclosed light pixels in the
illustrations while making the generated white sheet background transparent.
The live scene places its measured frames independently and never derives room
legality, routing, collision, or save state from this decoration. Its source
SHA-256 is
`0B208CE937A5B6E7C93AEE1E0061084F98C58DD10845ECF550892F2D020E6BCA`.
