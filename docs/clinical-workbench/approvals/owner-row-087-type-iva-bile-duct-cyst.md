term “choledochal cyst.” The scope is Type IVA anatomic classification from

## Exact approved versions

### 2A

A middle-aged patient with intermittent abdominal pain and jaundice has MRCP
showing multiple cystic dilatations involving both intrahepatic and
extrahepatic bile ducts. Which Todani subtype fits?

A. Type IVA
B. Type IVB
C. Type V

**Answer: A.** Type IVA includes intrahepatic and extrahepatic involvement.

### 2B

An adult patient has a congenital bile duct cyst (commonly called a
choledochal cyst) discovered during outpatient imaging. MRCP shows multiple
cystic dilatations involving intrahepatic and extrahepatic bile ducts. Which
classification is appropriate?

A. Type IVA
B. Type I
C. Type IVB

**Answer: A.**

### 2C

A patient’s specialist note identifies a Type IVA congenital bile duct cyst.
Which anatomic distribution should the clinic team expect on the reviewed
imaging?

A. Multiple cystic dilatations involving both intrahepatic and extrahepatic bile ducts
B. Multiple extrahepatic dilatations with normal intrahepatic ducts
C. Intrahepatic dilation without extrahepatic involvement

**Answer: A.** The second pattern is IVB; intrahepatic-only disease corresponds
to Type V/Caroli disease.

### 2D

A patient is referred after MRCP demonstrates a congenital bile duct cyst, and
the clinician contrasts Type IVA with Type IVB. Which statement correctly
identifies Type IVA?

A. It includes multiple cystic dilatations involving both intrahepatic and extrahepatic bile ducts
B. It is confined to multiple extrahepatic duct dilatations
C. It is confined to intrahepatic duct dilation

**Answer: A.**
