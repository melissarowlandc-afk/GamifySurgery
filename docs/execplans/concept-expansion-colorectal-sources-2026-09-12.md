# Colorectal source brief — September 12

## Scope and status

This source-only brief supports possible authoring of eight new, unapproved
prototype concepts. It does not approve clinical content, prescribe care, or
authorize runtime changes. Every future record remains
`needs_clinician_review` with a null named-clinician review.

The four proposed families do not duplicate an active stable objective:
existing content covers FIT-positive colonoscopy, colonic lipoma, fissure,
hemorrhoids, IPAA pouchitis, colon cancer staging/resection, rectal
response/watch-and-wait, and anal-HSIL/HPV association. It does not teach FAP
phenotype/surgical selection, complex fistula mapping and sphincter-safe
planning, recovery-phase diverticulitis evaluation and individualized elective
resection, or confirmed anal squamous-cancer referral.

## Recommended encounter boundaries

- FAP begins after an existing colonoscopy has established diffuse adenomas.
  The first gate is hereditary-polyposis counseling/germline testing, with a
  pathogenic APC result; the second decision uses the explicit rectal burden,
  intact continence, and restoration goal to select restorative
  proctocolectomy/IPAA referral.
- Use an external pelvic MRI result gate for a recurrent high transsphincteric
  fistula. The result must establish substantial external-sphincter involvement
  and no undrained abscess before the loose-seton/staged-planning decision. A
  new honest MRI service contract may be needed if existing generic or
  extremity MRI routes cannot truthfully represent it.
- Use an external lower-GI endoscopy result gate for recovered first
  complicated diverticulitis with no recent adequate colonoscopy. Return a
  negative alternative-lesion examination, then make node two a shared,
  individualized elective-resection discussion.
- Anal-SCC biopsy and chemoradiation are referral-pathway content, not clinic
  treatment. Use one externally ordered specialist contract for lesion tissue
  biopsy **and named staging evaluation**; only that combined order may return
  tissue confirmation and localized/nonmetastatic staging together. Every
  test-bearing alternative needs its own timing estimate. Do not simulate
  radiation delivery or allow a biopsy-only order to yield a CT result.
- Keep all four families stable outpatient evaluation/referral presentations,
  not emergency abscess care or an onsite colectomy/fistula operation.

## Open authoring checks

1. Root clinical review should approve the exact FAP phenotype and germline
   panel wording. The returned pathogenic APC result establishes context but
   must not become a stand-in for the explicit rectal phenotype behind IPAA.
2. Fistula variants must establish recurrent high transsphincteric anatomy,
   substantial external-sphincter involvement, and no undrained abscess before
   the MRI result drives loose-seton/staged planning.
3. Diverticulitis variants need a documented first recovered abscess episode,
   no recent colonoscopy, a negative return result, and symptom/complication
   burden for a shared elective-resection discussion.
4. Anal-SCC variants must distinguish anal-canal localized disease from
   perianal-margin exceptions. The initial external order must name both biopsy
   and staging studies if node two refers for chemoradiation; otherwise node
   two must complete staging rather than assume it.
