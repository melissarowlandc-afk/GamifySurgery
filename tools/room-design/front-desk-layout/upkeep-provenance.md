# Front Desk upkeep display atlas

The new parent-reviewed candidate source is `Photos for Codex 2/Codex Rooms 2/GS-015/front-desk-upkeep-atlas-01.png` (1254 x 1254 RGBA), generated with the built-in image tool. Its exact prompt is preserved beside it as `front-desk-upkeep-atlas-01.prompt.txt`; the source PNG remains unchanged. Owner review is still pending.

`pack-upkeep-assets.py` uses equal-size, baseline-registered technical crops for the full and empty water cooler states. Both states retain one shared source base calibration and render onto the accepted A5 floor footprint. The two litter clusters use alpha-derived technical crops with transparent padding. The script packs these unchanged pixels without rotation into a quality-82 WebP browser preview. This is a lossy display encoding; it is not a replacement source or a semantic repaint.

The litter clusters are nonblocking floor items at D1 and B4 in this isolated proof. Their pickup targets are the same floor tiles. The cooler remains permanent and visually nonblocking, with a B5 refill service point. The current runtime blocks the cooler's whole A5 tile and uses B5 for refill; that collision mismatch remains explicit pending later integration.
